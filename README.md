# homebrew-worktracker

Homebrew tap for [WorkTracker](https://github.com/alontzukerman/worktracker) — a small
macOS app that measures how much you're actually working.

## Install

```bash
brew tap alontzukerman/worktracker
brew install --cask --no-quarantine worktracker
```

`--no-quarantine` is required because the app isn't notarized by Apple.

## Update

```bash
brew upgrade --cask worktracker
```

## Uninstall

```bash
brew uninstall --cask worktracker          # remove the app
brew uninstall --zap --cask worktracker    # also delete your tracked data
```

---

### For the maintainer

`Casks/worktracker.rb` is generated by `npm run release` in the app repo — it
stamps the version, URL and sha256. Copy the generated file here and push; that
is what publishes an update to everyone.
